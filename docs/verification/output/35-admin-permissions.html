Group Permission Control - "General"
How to set permissions:
  • Most roles are restrictive, which means that selecting a category or forum from the list will make the resource unavailable to the user or group being edited.
  • Choosing "Allow All" will turn the resource available for all categories or forums. Exceptions to the case will be written in the permission box, when applicable.
  • To correctly configure access options is not a trivial task, so read the instructions carefully and, when in doubt, refer to http://www.jforum.net/help.htm and http://www.jforum.net/community.htm for help and support.

    Categories

    Forums
      Restricted Forums
    Anonymous Posts
      Deny anonymous posts
    Reply Only
      Deny create new Topics but allow replying to existing messages (e.g, Announcement Forums)
    Sticky or Announcement Topics
      Can create sticky or announcement topics
    Poll Topics
      Can create poll topics
    Vote
      Can vote on polls
    Read-Only Forums
      Read-Only forums. Choosing 'Allow All' will disable the read-only flag
    Moderation of replies
      To moderate or not replies to moderated Forums. Choosing 'Allow all' will disable moderation of replies, while selecting some forum will force replies to wait for moderation
    HTML messages
      HTML is NOT allowed in the selected forums. Choosing 'Allow all' will allow HTML in all forums
    Karma
      Enable Karma
    Bookmarks
      Enable Bookmarks
    Attachments
      Enable Attachments
      Allow download of existing Attachments.
    If the previous role is allowed for the same forum, then downloads will automatically be allowed, no matter what is chosen here.
